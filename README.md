# Uday Mahankali Portfolio — v1

A responsive cream-and-black personal portfolio homepage.

## Run it
This is a static website; no Node.js setup is needed.
1. Extract the ZIP.
2. Open `index.html` in a browser, or open the folder in VS Code and use Live Server.

## Included
- Supplied profile photograph
- About, skills, planned projects, certifications, campus activities and contact sections
- Nine certificate PDFs copied into `assets/certificates`
- Responsive mobile navigation

## Before publishing
- Review the skills list and make sure you can demonstrate each skill.
- Add your real GitHub profile URL.
- Add project links only after VeriDoc AI and CRIPTIFY are built.
- Add certificate verification links where available.
- Review contact and social links.
- Your creative portfolio remains a separate future site.

VeriDoc AI and CRIPTIFY are clearly marked PLANNED, not completed.
